Methodology and limits

Research jobs make read-only requests to each application’s public website. A successful probe confirms only that the public site responded; it does not verify login options, MFA, signup requirements, or API access. Those fields remain unknown until supported by evidence.

The workflow does not create accounts, submit personal information, bypass CAPTCHA or MFA, or access paid resources. Job logs record probe outcomes.
